# Fuga Lógica

## Jogo digital de Lógica Matemática. 
Um carro foge da polícia por uma rodovia cheia de sinais. Cada sinal só abre quando o jogador resolve uma condição de Lógica Proposicional. Quanto mais rápido ele acerta, mais distância abre da viatura. Enquanto o carro está parado, a viatura se aproxima.

- **Lógica e regras:** Python (Flask)
- **Interface:** HTML, CSS e JavaScript no navegador
